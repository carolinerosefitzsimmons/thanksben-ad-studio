# Pre-rendered trusted-by logos

One flat `#002923` PNG per customer, used by the landing page's trusted-by row.
Generated by `node scripts/fetch-client-logos.mjs`, which reads `data/clients.json`.

The landing page falls back to the customer's name as text when a file is
missing, so an absent logo is safe — a **wrong** one is not.

- **Seven could not be fetched** — Zalando, Pleo, Sigma Connected, Thriva,
  Deliveroo, Mondelez, Flat Iron. All block automated requests. Set

- **Two were fetched and deleted** — British Airways scraped a fragment of the

Always look at what this script produces before shipping it. It scrapes
`og:image` and favicons, which are frequently the wrong mark.
