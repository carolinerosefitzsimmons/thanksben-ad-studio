# Pre-rendered trusted-by logos

One flat `#002923` PNG per customer, for the landing page's trusted-by row.
Generated by `node scripts/fetch-client-logos.mjs`, which reads `data/clients.json`.

A **missing** logo is safe — the page falls back to the customer's name as text.
A **wrong** one is not. So the rule is: run the script, look at every file, keep
only what you can positively identify.

## Current state: 9 of 29, hand-checked

Kept: 10x Banking, Bitpanda, Fastmarkets, Fever-Tree, HSBC, InPost, JTI,
Sigma Connected, Trainline.

## Why automated sourcing cannot be trusted here

The script draws from two sources and prefers the widest result, because a
wordmark is wide and an icon is square. Neither source is dependable:

- **logo.dev** returns the *correct brand* but almost always its square icon.
  A row of abstract icons is not social proof — nobody recognises a hexagon.
- **Scraping the company's own page** often finds the real wordmark, but just as
  often finds something else entirely. Real results from the last run: a
  **Trustpilot badge** for Funding Circle and Octopus Energy, **"EY Parthenon"**
  for EY, **"Youth Kitchen"** (itsu's charity) for itsu, and a stray fragment of
  the BA speedmarque for British Airways.

Everything in that list was deleted by hand. Correct-but-icon-only marks
(Chattermill, Lightricks, Improbable, MUFG, Flat Iron) were also dropped, since
the text fallback tells a reader more than an unlabelled symbol does.

## Note on the logo.dev token

`LOGO_DEV_TOKEN` accepts either kind of key:

- `pk_...` (publishable) is used directly against `img.logo.dev`
- `sk_...` (secret) goes through the Brand Search API instead

A rejected token now fails loudly. It previously fell through to scraping while
still reporting "Source: logo.dev", which is how the Trustpilot badges got in.

## Getting the rest

Ten customers have no usable logo. The quickest fix is to drop the official
wordmark SVG or PNG into this folder by hand, named `<domain-with-dashes>.png`,
and let the script's recolouring be skipped. Anything absent simply renders as
text, so there is no rush.
